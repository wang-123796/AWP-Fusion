# AWP-Fusion: A Multi-Model Framework for Protein Property Prediction

This repository contains the official implementation for **AWP-Fusion** and three baseline models (AWP, OphPred, Seq2) for predicting protein properties (pHopt, Tm, and Topt). Our method is based on a **balanced weighted pooling** (AWP) mechanism, which is fused with standard mean pooling (Fusion) to achieve robust prediction.

---

## 📁 Repository Structure

The codebase is organized into four independent model modules (one folder per model):

```text
AWP-Fusion_Project/
├── data/
│   ├── raw/                  # Raw CSV files (train_pH.csv, test_pH.csv, ...)
│   ├── processed/            # ESM features (.pt files) — generated by extract_feature.py
│   ├── weights/              # Best weights for different task
│   └── extract_features.py   # Script to generate ESM features from raw sequences
├── model_awp/                # Model 1: AWP (Balanced Weighted Pooling + KNN)
├── model_awp_fusion/         # Model 2: AWP-Fusion (Mean + Weighted Pooling Fusion)
├── model_oph_pred/           # Model 3: OphPred (Mean Pooling + KNN Baseline)
├── model_seq2/               # Model 4: Seq2 (Original Deep Learning Baseline)
└── results/                  # All output predictions and figures

1. Data Setup
1.1 Raw Data
The raw CSV files are already included in this repository under data/raw/, with the naming convention train_<task>.csv and test_<task>.csv (where <task> is one of pH, Tm, or Topt).

1.2 ESM Model Weights
We use ESM-2 (esm2_t33_650M_UR50D) to generate 1280-dimensional sequence embeddings. Before generating features, you must download two model weight files and place them in the data/ directory.

Download the following two files:

Main model weights (~2.5 GB):

text
https://dl.fbaipublicfiles.com/fair-esm/models/esm2_t33_650M_UR50D.pt
Contact-regression weights:

text
https://dl.fbaipublicfiles.com/fair-esm/regression/esm2_t33_650M_UR50D-contact-regression.pt
Place both files here:

text
data/
├── esm2_t33_650M_UR50D.pt
└── esm2_t33_650M_UR50D-contact-regression.pt
⚠️ Both files are required. The main weights file references the contact-regression file internally, and the loading function will fail if the latter is missing.

1.3 Generate ESM Features
Once the weights are in place, run the feature extraction script from the project root:

bash
python data/extract_features.py data/raw/train_pH.csv    data/raw/test_pH.csv
python data/extract_features.py data/raw/train_Tm.csv    data/raw/test_Tm.csv
python data/extract_features.py data/raw/train_Topt.csv  data/raw/test_Topt.csv
The script automatically parses the task name and split from each filename, and saves the output to the corresponding folder under data/processed/:

text
data/processed/
├── pH_sequence_train_feat/
├── pH_sequence_test_feat/
├── Tm_sequence_train_feat/
├── Tm_sequence_test_feat/
├── Topt_sequence_train_feat/
└── Topt_sequence_test_feat/
Each .pt file contains a tensor of shape (sequence_length, 1280), corresponding to the last-layer representation from ESM-2.

3. Quick Start & Reproduction
All models can be run independently. Navigate to the corresponding model folder and run the commands below.

Model 1: AWP (Balanced Weighted Pooling + KNN)
Note: --best_T is the optimal temperature for the task (e.g., 0.5).

bash
cd model_awp

python run.py --task pH   --best_T 0.5
python run.py --task Tm   --best_T 0.5
python run.py --task Topt --best_T 0.5
Model 2: AWP-Fusion (Mean + Weighted Fusion)
Note: This model relies on the trained weights from Model 1 (AWP).

bash
cd model_awp_fusion

python run.py --task pH   --best_T 0.5
python run.py --task Tm   --best_T 0.5
python run.py --task Topt --best_T 0.5
Model 3: OphPred (Mean Pooling + KNN Baseline)
bash
cd model_oph_pred

python run.py --task pH
python run.py --task Tm
python run.py --task Topt
Model 4: Seq2 (Deep Learning Baseline)
Note: Requires GPU. Set --target_col to pHopt, tm, or topt accordingly.

bash
cd model_seq2

python main.py --task pH   --target_col pHopt
python main.py --task Tm   --target_col tm
python main.py --task Topt --target_col topt
4. Plotting Figures
AWP Model Plotting
For the pH task, all figures (training curve, weight distribution) will be generated. For Tm and Topt tasks, only the training curve is generated.

bash
cd model_awp

# pH task (Generate all figures)
python plot.py --task pH --best_T 0.5 --type all

# Tm or Topt task (Generate only training curve)
python plot.py --task Tm   --best_T 0.5
python plot.py --task Topt --best_T 0.5
All figures will be saved to the results/{task}/figures/ directory.
